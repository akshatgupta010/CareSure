# Medic Support

AI-assisted medical insurance claim validation prototype built with React + Vite.

## Run
```bash
npm install
npm run dev
```

Open the Vite URL shown in the terminal.

## Demo flow
Login → Dashboard → New Claim → Start AI Validation → Claim Validation → Human Review Queue.

The prototype uses mock data and mock AI processing. It intentionally does not make automatic fraud, approval, or rejection decisions.
